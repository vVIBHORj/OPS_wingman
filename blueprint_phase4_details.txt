14.3 Provenance requirement
Every policy-dependent decision should be able to identify the policy version and evidence used. This makes later investigation possible when a decision is challenged.
15. ML Layer
ML will be used where a learned signal adds value instead of forcing every step through an LLM.
15.1 Initial ML candidate: operational risk
Inputs: order amount, refund history, account age, refund frequency, chargeback history, delivery history, etc.
Model candidates: XGBoost or LightGBM.
Output: calibrated risk probability or risk band.
15.2 Anomaly detection candidate
Detect unusual invoice/order/refund behavior.
Candidate method: Isolation Forest or a similar unsupervised baseline.
15.3 ML verification
Train/validation/test split must be defined.
Track precision, recall, false-positive rate and calibration where appropriate.
Model version and feature schema must be stored with the decision trace.

16.3 Core rule
Never trust the model with authorization
The LLM may propose an action. The backend decides whether that action is permitted, whether the user/agent has the required permission, whether policy conditions are satisfied and whether approval is required.

  -> timeout / duplicate / injection / mismatch / restart

  -> throughput / latency / queue / DB behavior
20.2 Critical failure scenarios
Order API returns HTTP 500.
Courier API times out.
LLM returns malformed structured output.
Same webhook is delivered twice.
Payment succeeds but the workflow crashes before recording the result.
Order and payment totals disagree.
Customer requests data belonging to another customer.
Prompt injection attempts to override policy.
High-risk refund is proposed without approval.
Workflow restarts while waiting for approval.
20.3 Required automated assertions
Correct tools were selected and called with valid parameters.
No unauthorized action was executed.
High-risk workflows stop for approval.
Duplicate events do not duplicate financial or state-changing actions.
A failed external call does not leave the system in an unknown state.
Final state matches expected ground truth.
Audit trail exists for every material action.
