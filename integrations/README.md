# External Integrations Subsystem

This module houses service adapters and high-fidelity local mocks for third-party systems.

## Modules
- `mock/`: Local mock endpoints for payment gateways, couriers, and ERPs.
- `gmail/`: Email channel adapter.
- `razorpay/`: Payment tracking & refund gateway adapter.
- `shopify/`: Order and inventory synchronization adapter.
- `whatsapp/`: Customer messaging channel adapter.
